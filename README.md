# Art Dent Clinic 🦷

A modern and responsive dental clinic website designed to provide a professional and comfortable digital experience for patients.

## ✨ Features

- Modern and responsive design
- Dental services pages
- Doctor profiles
- Before & After dental cases
- Online appointment page
- Digital dentistry and technology section
- Clinic information
- WhatsApp contact integration
- Mobile-friendly layout

## 🛠️ Technologies

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- Font Awesome
- Google Fonts
- Media Queries
- Responsivness
